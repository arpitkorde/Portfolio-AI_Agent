## Reporting a Vulnerability

We take security vulnerabilities seriously.

If you discover a security vulnerability within this project, please send an e-mail to **chanchal031@gmail.com**. All security vulnerabilities will be promptly addressed.

**Please do NOT open an issue for a security vulnerability.** Instead, please email us directly with the details of the vulnerability so we can address it privately.

Thank you for helping keep this project safe and secure!
